# Post-Quantum Migration: An Engineer's Playbook — companion repository

Lab code, tests, the regulatory calendar, the templates and the reference environment for
*Post-Quantum Migration: An Engineer's Playbook* (Avishek Nag, 2026). Every number printed in
the book was produced by a script in this repository; the `results/` folder of each lab holds the
run the book quotes, so you can diff your own run against it.

The book is the explanation. This repository is the evidence, and the place where the two living
appendices are kept current: `calendar/deadlines.yaml` (Appendix A) and [ERRATA.md](ERRATA.md)
(corrections and the status changes to Appendix C since printing).

## Layout

```
labs/chNN/                one folder per chapter
  README.md               what the labs do, the commands, "Tested with" versions
  starter_*.py            your file: functions raise NotImplementedError until you write them
  tests/                  acceptance tests (pytest); run against your starter or the reference
  solution/               the reference implementation the book's numbers came from
  fixtures/               test vectors from the standards (RFC 8554, X-Wing, PKCS#11 3.2 header)
  results/                the book's measured outputs (JSON + printed tables)
calendar/deadlines.yaml   the regulatory calendar, one entry per dated obligation (Lab 1.1 reads it)
templates/                supplier questionnaire, migration test plan, rollout runbook (Appendix F)
Dockerfile                the reference environment (Appendix D)
requirements.txt          Python packages at the versions the book measured with
ERRATA.md                 corrections and status changes since printing
```

## Running the labs

The quickest path is the container, which builds OpenSSL 3.5, OpenSSH 10 and liboqs from source
and pins every Python package (10 to 20 minutes the first time):

```bash
docker build -t pqm-labs .
docker run --rm -it -v "$PWD":/work pqm-labs bash
```

Inside it, or on a machine set up per Appendix D:

```bash
pytest labs/ch05/tests                        # your starter (fails until you complete it)
PQ_LAB_IMPL=solution pytest labs/ch05/tests   # the reference implementation
PQ_LAB_IMPL=solution pytest labs               # every chapter
python labs/ch12/solution/testplan.py          # the whole migration test plan (Lab 12.3)
```

Each lab's `README.md` lists the individual scripts. Two labs need things the container cannot
hold: Lab 10.3 needs AWS credentials (it prints the request shapes without them) and Lab 5.1's
observer needs a TLS endpoint you are allowed to sit in front of (the labs run their own on loopback).

### Without the container

| Chapters | Needs |
|---|---|
| 1–4 | Python 3.11+, `pip install pyyaml jsonschema pytest` |
| 2 | `cryptography` 48+; optionally `liboqs-python` for the SLH-DSA, Falcon and HQC rows |
| 5, 7, 9, 11, 12 | OpenSSL 3.5+ on the path or in `OPENSSL_BIN` (macOS: `brew install openssl@3`); anything loading the library needs `LD_LIBRARY_PATH` |
| 6 | OpenSSH 9.9+ for the live test (`OPENSSH_PREFIX` if not the system one) |
| 7 | Go 1.22+ for Pebble (`go install github.com/letsencrypt/pebble/v2/cmd/pebble@latest`) |
| 8 | `hsslms` (RFC 8554 reference) |
| 10 | SoftHSM 2 + OpenSC, `python-pkcs11` (`SOFTHSM2_CONF` per `labs/ch10/softhsm/init.sh`) |
| 11 | `hypothesis`, `pyyaml` |
| 12 | Go 1.24+ for the TLS harness (`go build` in `labs/ch12/gotls`) |

Exact versions used for the book are in `requirements.txt` and Appendix D.

## Conventions

`PQ_LAB_IMPL=solution` makes a chapter's tests import `solution/` instead of your starter. Later
labs import earlier ones (Chapter 7 and 12 use the Chapter 5 observer; Chapter 9 uses the Chapter 7
CA; Chapter 11 uses the Chapter 9 X-Wing), so run from the repository root. Files under
`labs/ch07/ca/`, `labs/ch09/data/` and `labs/ch10/softhsm/tokens/` are generated by the labs and
ignored by git.

## Contributing and reporting

Corrections to the book: open an issue with the page number and the sentence; accepted ones go into
`ERRATA.md`. Calendar changes: a pull request against `calendar/deadlines.yaml` with the primary
source in the `summary` or a comment and today's date in `verified`. Status changes to Appendix C:
an issue with the source; the matrix is republished in `ERRATA.md`.
